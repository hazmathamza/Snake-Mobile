# Snake Mobile

A fully functioning Snake game, optimized for mobile. No dependencies, no build step — just open `index.html` in a browser.

## Play

- **Swipe** anywhere on the board to steer
- **On-screen D-pad** below the board
- **Keyboard** (desktop): arrow keys / WASD, Space to pause

Eat the food to grow. The snake speeds up as you eat. Don't hit the walls or yourself.

## Features

- Responsive board that fits any phone screen (portrait or landscape)
- Touch-first controls: swipe + large D-pad buttons, no page scroll or zoom while playing
- Score + best score saved on your device
- Pause / resume, auto-pause when the tab goes to the background
- Speed increases as you eat; gentle haptic feedback on supported phones
- Add it to your home screen for a fullscreen, app-like experience

## Run it

Open `index.html` directly, or enable GitHub Pages on this repo (Settings → Pages → Deploy from branch `main`) for a shareable link.
